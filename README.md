## About the Project

EV ChargeMap Intelligence is my internship project on EV charging infrastructure in India.

The main purpose of this project is to understand the current charging station data, find important patterns, identify unusual charging capacities and compare infrastructure across states.

The project also explores how data analytics can be used to support EV charging infrastructure planning.

### Main Question

**Where should EV charging infrastructure receive more attention based on the available data?**

---

## Project Objectives

- Analyze EV charging station data.
- Clean and prepare the data for analysis.
- Check the operational status of charging stations.
- Compare charging infrastructure across states.
- Find high-capacity unusual stations.
- Use K-Means clustering to group charging stations.
- Calculate a project-specific Station Priority Score.
- Create a Power BI dashboard to present the results.

---

## Datasets Used

### 1. EV Charging Stations

This is the main dataset used in the project.

**Records:** 1,000

It contains information such as station location, state, charging points, status and operator.

### 2. Indian EV Sales

This dataset was used to understand the overall EV sales trend.

**Period:** 2015–2025

It contains information about EV sales and EV penetration.

### 3. India Cities Lat/Lng

This dataset provides geographic and population information about Indian cities.

**Records:** 188 cities

It was mainly used as supporting geographic information.

## Key Results

Some of the main results obtained from the charging station dataset are:

- **1,000** charging stations
- **2,364** total charging points
- **969** operational stations
- **96.9%** operational rate
- **2,320** active charging points
- **87** high-capacity anomalies
- **4** K-Means clusters

A station with **600 charging points** was identified as the largest high-capacity outlier in the dataset. The record was checked and retained for analysis.

---

## Statistical Analysis

The project used basic statistical methods such as:

- Mean
- Median
- Standard Deviation
- Interquartile Range (IQR)
- Outlier Detection

The analysis showed that charging capacity is not evenly distributed across all stations.

---

## Machine Learning

K-Means clustering was used to group charging stations based on:

- Latitude
- Longitude
- Charging Points

The features were standardized before applying K-Means.

The Elbow Method was used and **4 clusters** were selected for the analysis.
